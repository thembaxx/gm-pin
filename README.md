# Google Map Pin

An address-search interface for displaying a selected location on a map.

[Browse the source](https://github.com/thembaxx/gm-pin)

## Engineering highlights

React, Vite and the vis.gl Google Maps integration. Map-service access requires valid provider configuration.

## Technology

Declared in [package.json](package.json): React `^18.3.1` · TypeScript `~5.6.2` · Tailwind CSS `^3.4.17` · Vite `^6.4.3` · vis.gl Google Maps `^1.4.3`.

**Quality tooling:** `lint` scripts are available. See the setup guide below for prerequisites; this documentation pass does not assert that those checks were run.
